# SKU 构成管理后台

硅基流动风格后台管理页面 —— 「商品定价中心 / GPU 库存 / SKU 构成」三级菜单下的 SKU 构成关系管理。

## 数据模型

每一行描述一条 **父子 SKU 构成关系**（BOM 式）：

| 字段 | 说明 |
| --- | --- |
| `SKU Definition` | 构成定义分组名，同一定义下共享一套构成规则 |
| `上级 SKU` | 被组合出来的商品规格 |
| `下级 SKU` | 被计入组合的原子规格 |
| `作用` | 该下级在此组合中承担的角色（gpu / cpu / memory / disk / network …） |
| `数量` | 该下级在上级中的个数 |

约束：同一 `SKU Definition` 下，`上级 + 下级 + 作用` 唯一。

## 功能

- **增删改查**：新增 / 编辑弹窗（必填校验、数量正整数校验、重复关系拦截）、单条删除、勾选批量删除
- **筛选**：SKU 名称包含、售卖项包含、SKU 定义、SKU ID；点击表格中的 SKU 名称可快速按该 SKU 过滤
- **视图**：明细表格（`Definition` / `上级 SKU` 按 rowspan 合并）与树形视图切换
- **排序分页**：数量列升降序、每页 10 / 20 / 50 / 200 条
- **导入导出**：导出当前筛选结果为 CSV；导入支持 JSON 与 CSV，自动去重合并
- **持久化**：数据存于浏览器 `localStorage`，刷新不丢；右上角可一键恢复示例数据

## 说明

纯前端单文件实现，无构建步骤、无外部依赖，数据仅保存在本地浏览器。
若要接入真实后端，将 `state.rows` 的读写替换为 API 调用即可，数据结构已分离。
