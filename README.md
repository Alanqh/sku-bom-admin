# SKU 构成管理后台

硅基流动风格后台管理页面 —— 「商品定价中心」下的 `GPU 库存` 与 `SKU 构成` 平级菜单，用于维护 SKU 构成关系。

## 数据模型

每一行描述一条 **父子 SKU 构成关系**（BOM 式）：上级 SKU 由「数量 × 下级 SKU」组成。

| 字段 | 说明 |
| --- | --- |
| `上级 SKU` | 被组合出来的商品规格 |
| `上级 SKU ID` | 上级 SKU 的唯一标识，纯数字 |
| `下级 SKU` | 被计入组合的原子规格 |
| `下级 SKU ID` | 下级 SKU 的唯一标识，纯数字 |
| `作用` | 该下级在此组合中承担的角色（gpu / cpu / memory / disk / network …） |
| `数量` | 该下级在上级中的个数 |
| `创建时间` | 该条构成关系首次录入的时间 |
| `更新时间` | 该条构成关系最近一次编辑的时间，编辑过会带「改」标记 |

约束：

- 同一「上级 + 下级 + 作用」唯一（不重复录入同一构成关系）。
- 上级 SKU 与下级 SKU 不能相同；上下级 SKU ID 也不能相同。
- **SKU ID 归属于 SKU 本身**：同一个 SKU 无论作为上级还是下级出现，在整张表里始终是同一个 ID。

## 功能

- **增删改查**：新增 / 编辑弹窗（必填校验、数量正整数校验、重复关系拦截、上下级互斥校验）、单条删除；保存后自动跳到该记录所在页
- **筛选**：SKU 名称包含、SKU ID 包含、指定 SKU；点击表格中的 SKU 名称可快速按该 SKU 过滤
- **视图**：明细表格（逐行展示，无合并单元格）与树形视图切换
- **排序分页**：数量 / 创建时间 / 更新时间三列互斥排序（升序 → 降序 → 取消），每页 10 / 20 / 50 / 200 条
- **持久化**：数据存于浏览器 `localStorage`，刷新不丢；右上角可一键恢复示例数据

## 说明

纯前端单文件实现，无构建步骤、无外部依赖，数据仅保存在本地浏览器。
若要接入真实后端，将 `state.rows` 的读写替换为 API 调用即可，数据结构已分离。
